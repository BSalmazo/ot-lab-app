# Experiments

Every number Liscere publishes traces to a run id and a capture hash. This folder holds the
traceable record.

- `captures/MANIFEST.json`: copy of the index of archived bench captures (LiscereSecurity/Bench-Data).
- `EXP-<yyyy>-<nn>-<slug>/`: one folder per experiment, holding the scenario file, the run ids, the
  metrics output and a short README (convention introduced with MODERNISATION_PLAN item 7).
