# Studies and Research Material

This directory keeps research evidence and writing packages separate from the user-facing Railway application.

## Contents

- `checkpoint/` - functional checkpoint tooling, approved run notes, selected evidence files, paper package, and TRP package from the earlier checkpoint campaign.
- `chapter4_modbus_tcp_test_log.md` - consolidated chapter 4 Modbus/TCP validation log.
- `dossiers/` - self-contained technical dossiers for TRP and thesis writing.
- `evidence/` - raw evidence exports, benchmark outputs, and screenshots used by the current dossier.

These files are useful for thesis, paper, reproducibility, and project history work. They are not imported by the web app or required for users to run the dashboard or download the agent.
